    └──────────┼─────────────────────┼────────────────────┼───────────┘
               │                     │                    │
               └─────────────┬───────┴────────────────────┘
                             │
                             ▼
    ┌─────────────────────────────────────────────────────────────────┐
    │  1. DATA INGESTION  (DataIngestionService)                      │
    │                                                                  │
    │  ┌──────────────────────────────────────────────────────────┐   │
    │  │  fetch_fixtures_for_date(target_date)                     │   │
    │  │                                                            │   │
    │  │  For each league (PL → LL → SA → BL1 → FL1):             │   │
    │  │    1. Try ESPN scoreboard API                              │   │
    │  │    2. If no data + API key → football-data.org             │   │
    │  │    3. BL1 special: OpenLigaDB fallback                     │   │
    │  │    4. Dedup by (home_team, away_team, date)                │   │
    │  │    5. Create/Update Match records                          │   │
    │  └──────────────────────────────────────────────────────────┘   │
    │                                                                  │
    │  Triggered by:                                                   │
    │    • Celery Beat at 00:05 (6 days)                              │
    │    • On-demand from PredictionsView (subscriber lookahead)       │
    │    • Management command: fetch_and_predict                       │
    └────────────────────────────┬────────────────────────────────────┘
                                 │
                                 ▼
    ┌─────────────────────────────────────────────────────────────────┐
    │  2. FEATURE ENGINEERING  (FeatureEngineeringService)            │
    │                                                                  │

    │                                                                  │
    │  ┌──────────────┐  ┌────────────┐  ┌──────────────────────┐    │
    │  │ Recent Form  │  │ ELO Diff   │  │ Schedule Congestion  │    │

    │  └──────────────┘  └────────────┘  └──────────────────────┘    │
    │  ┌──────────────┐  ┌────────────┐  ┌──────────────────────┐    │
    │  │ Home/Away    │  │ Head-to-   │  │ Goal Patterns        │    │
    │  │ Split        │  │ Head (H2H) │  │ (avg, over 2.5 rate) │    │
    │  └──────────────┘  └────────────┘  └──────────────────────┘    │
    │  ┌──────────────────────────────────────────────────────────┐   │
    │  │ League Context (home win rate, draw rate, avg goals)      │   │
    │  └──────────────────────────────────────────────────────────┘   │
    └────────────────────────────┬────────────────────────────────────┘
                                 │
                                 ▼
    ┌─────────────────────────────────────────────────────────────────┐
    │  3. ENSEMBLE PREDICTION  (EnsembleService → EnsemblePredictor)  │
    │                                                                  │
    │  ┌──────────────────────────────────────────────────────────┐   │
    │  │                WEIGHTED AVERAGE                            │   │
    │  │                                                            │   │
    │  │   ┌──────────┐   ┌──────────┐   ┌──────────────────┐    │   │
    │  │   │ XGBoost  │   │ Neural   │   │ ELO (always-on)  │    │   │
    │  │   │ w = 0.4  │   │ w = 0.3  │   │ w = 0.3          │    │   │
    │  │   │          │   │ TF/Keras │   │ + home advantage  │    │   │
    │  │   └──────────┘   └──────────┘   └──────────────────┘    │   │
    │  │                                                            │   │
    │  │   If XGB or Neural unavailable → weight → ELO             │   │
    │  │   Cold start: ELO + random noise for variety              │   │

    │                                                                  │
    │  Output per match:                                               │

    │                                                                  │
    │  ┌─── Step A: Fetch final scores ──────────────────────────┐    │
    │  │  ESPN scoreboard → match.status = 'finished'             │    │
    │  │                    match.home_score / away_score set      │    │
    │  └──────────────────────────────────────────────────────────┘    │
    │                          │                                       │
    │  ┌─── Step B: Resolve predictions ─────────────────────────┐    │
    │  │  For each finished match with unresolved prediction:      │    │
    │  │    actual_outcome = match.actual_outcome                  │    │
    │  │    prediction.resolve(actual_outcome)                     │    │
    │  │    → is_correct = (predicted == actual)                   │    │
    │  │    → resolved_at = now()                                  │    │
    │  └──────────────────────────────────────────────────────────┘    │
    │                          │                                       │
    │  ┌─── Step C: Update ELO ratings (Online Learning) ────────┐    │
    │  │  FeatureEngineeringService.update_elo(match)              │    │
    │  │    K = 32                                                 │    │
    │  │    home.elo += K × (actual − expected)                    │    │
    │  │    away.elo += K × (actual − expected)                    │    │
    │  │  → ELO immediately reflected in next prediction           │    │
    │  └──────────────────────────────────────────────────────────┘    │
    │                          │                                       │
    │  ┌─── Step D: Accuracy snapshot ───────────────────────────┐    │
    │  │  AccuracyRecord per league + overall:                     │    │
    │  │    total, correct, incorrect, pending                     │    │
    │  │    accuracy_rate, home_win_acc, draw_acc, away_win_acc    │    │
    │  │    model_version, avg_confidence                          │    │
    │  └──────────────────────────────────────────────────────────┘    │
    │                          │                                       │
    │  ┌─── Step E: Retrain decision ────────────────────────────┐    │
    │  │  Trigger IF:                                              │    │
    │  │    ≥ 100 new resolved since last training   OR            │    │
    │  │    accuracy drift > 5% (last 7d vs all-time)              │    │
    │  │                                                            │    │
    │  │  → TrainingPipeline.run_incremental_update(days=90)       │    │
    │  │    → Build (X, y) from resolved matches                   │    │
    │  │    → Retrain XGBoost + Neural                             │    │
    │  │    → Promote only if ensemble accuracy improved           │    │
    │  └──────────────────────────────────────────────────────────┘    │
    └─────────────────────────────────────────────────────────────────┘


    ┌─────────────────────────────────────────────────────────────────┐
    │  7. WEEKLY FULL RETRAIN  (Monday 03:00 UTC)                     │
    │                                                                  │
    │  TrainingPipeline.run_full_training(seasons=3):                  │
    │                                                                  │
    │    1. Collect all finished matches (up to 3 seasons)             │
    │    2. Generate feature matrix (32+ columns)                      │
    │    3. Train XGBoost (gradient boosted trees)                     │
    │    4. Train Neural Network (TensorFlow dense layers)             │
    │    5. Evaluate: accuracy, per-outcome precision                  │
    │    6. Compare with current active ModelVersion                   │
    │    7. Promote if avg accuracy improved                           │
    │    8. Save model files to /app/models/                           │
    │                                                                  │
    │  Model Registry:                                                 │
    │    ModelVersion table: name, version, metrics, is_active         │
    │    Only ONE version active at a time                             │
    │    Previous versions retained for audit                          │
    └─────────────────────────────────────────────────────────────────┘


    ┌─────────────────────────────────────────────────────────────────┐
    │  8. DRIFT MONITOR  (Daily 06:00 UTC)                            │
    │                                                                  │
    │  check_accuracy_drift(threshold=0.05):                           │
    │                                                                  │
    │    recent_accuracy  = last 7 days correct / total                │
    │    baseline_accuracy = all-time correct / total                  │
    │    degradation = baseline − recent                               │
    │                                                                  │
    │    IF degradation > 5%:                                          │
    │      → ALERT: "Accuracy dropped by X%"                          │
    │      → TRIGGER: incremental retrain (last 90 days)              │
    │      → LOG: retrain result + new model metrics                   │
    └─────────────────────────────────────────────────────────────────┘
